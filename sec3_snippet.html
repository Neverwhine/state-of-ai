ANATOMY OF AN AI AGENT

Every agentic product — from Cursor to Harvey to Glean — is built on the same fundamental layers.

THE 7-LAYER AGENT STACK

1 UI / Frontend Layer How agents meet users
CopilotKit / AG-UI DVC Vercel AI SDK Streamlit
12.4K GitHub ★ in <1 year — AG-UI

AG-UI is becoming the standard event protocol for agent-to-user interaction.

2 Orchestration Layer Planning, routing, multi-agent coordination
LangGraph 129K ★ CrewAI AutoGen Semantic Kernel
Most serious startups eventually build proprietary orchestration

ReAct loops → multi-agent systems with planners, workers, verifiers.

3 Memory Layer State beyond the prompt window
mem0 49.6K ★ DVC Zep Letta / MemGPT
+26% accuracy over OpenAI Memory, 90% less tokens

mem0 externalizes memory from the agent framework — works with any stack.

4 Tool / Action Layer How agents interact with external systems
MCP 110.8M monthly PyPI A2A 22.5K ★ Function Calling
"MCP is becoming the REST of the AI era"

MCP for tools, A2A for agent-to-agent, AG-UI for agent-to-user.

5 Foundation Model Layer The reasoning engine(s)
OpenAI Anthropic Google xAI Open-weight models
37% of enterprises use 5+ models in production Source: a16z

Multi-model routing is now standard — Harvey uses 6+ providers.

6 Execution Layer Where code actually runs
E2B Daytona WebContainers Cloud VMs Local Runtime
3 patterns: local, cloud sandbox, browser-native

The execution choice defines the product: Cursor = local, Devin = cloud, Bolt = browser.

7 Evaluation / Monitoring Observability and quality
LangSmith Phoenix / Arize OpenTelemetry
Best startups treat eval as product, not afterthought

Harvey: BigLaw Bench. Perplexity: search_evals. Sierra: provider health monitoring.
